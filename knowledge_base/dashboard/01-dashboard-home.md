## Layout

The dashboard welcomes the user with a personalized greeting: "Welcome to your Learning Portal, [Name]!"

## Main Action Cards

### 1. Start Practice Session
- **Description**: "Begin a new practice session to enhance your communication and professional skills"
- **Action**: Opens the practice session interface
- **Icon**: Play button icon (blue/purple gradient button)

### 2. Socratic Exercises
- **Description**: "Checkout socratic exercises for oops, system design and database design."
- **Action**: Opens the Socratic exercise library
- **Icon**: Book/open-book icon (blue/purple gradient button)

### 3. Settings
- **Description**: "Customize your learning experience"
- **Action**: Opens the settings page to configure learning preferences
- **Icon**: Gear icon (gray button)

## Past Sessions Analytics

The Past Sessions section contains analytics with three tab views:

### Score Tab (Default)
- Line chart showing score progression over time
- X-axis: Weekly date ranges (e.g., "Mar 1 – Mar 8", "Mar 8 – Mar 15", etc.)
- Y-axis: Score from 0.0 to 4.0+
- Shows user's name with a data line legend

### Passages Attempted Tab
- Shows the number of passages the user has attempted over time

### Time Spent Tab
- Shows the amount of time the user has spent on the platform over time

### Stats Table
Below the chart, a detailed table shows:
| Column | Description |
|--------|------------|
| Date | The date range for the session |
| No of Passages | Number of passages attempted |
| Percentage Effort | How much effort was put into the session |
| Avg Communication Score | Average communication score for that period |

Note: "Stats are calculated once per day."
