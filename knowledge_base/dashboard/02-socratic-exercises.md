## Socratic Guide Methodology
The exercises use a Socratic method where:
1. The system poses thought-provoking questions
2. Users think critically and respond
3. The system provides hints and guidance (multi-level hint system)
4. Users build understanding through guided discovery
5. AI feedback provides detailed analysis of responses

## Exercise Format
Each exercise is a guided, multi-step design or coding challenge where:
- A split-screen editor allows users to write and test solutions
- Level progression moves users through increasing complexity
- Hints are available at multiple levels if users get stuck
- AI grading evaluates both correctness and approach
